# Phigros

A Phigros-style rhythm game replica with dynamic judgment line mechanics, built with Flutter and Flame.

## Tech Stack

- **Framework:** Flutter + Dart
- **Game Engine:** Flame
- **Audio:** audioplayers
- **Platform:** iOS / macOS / Android

## Project Structure

```
lib/
  core/           — Shared utilities
  game/           — Game engine & components
  screens/        — UI screens
  widgets/        — Reusable widgets
```
